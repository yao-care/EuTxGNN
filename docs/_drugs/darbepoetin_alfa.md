## Cytotoxicity

Darbepoetin alfa is a supportive-care agent, not an antineoplastic drug, so no cytotoxicity assessment applies.

## Safety Considerations

- **Contraindications (knowledge graph, not label text)**: The TxGNN knowledge graph records contraindication links with hypertensive disorder and hypertension. This should be verified against the official product information.
- **Drug Interactions**: 17 interactions were identified.
  - **Major**: carfilzomib, lenalidomide, pomalidomide, thalidomide
  - **Moderate**: cyclosporine, human C1-esterase inhibitor, conestat alfa
  - **Minor**: ACE inhibitors (fosinopril, benazepril, captopril, enalapril, lisinopril, moexipril, perindopril, quinapril, ramipril, trandolapril)

Please refer to the SmPC for the full set of warnings and contraindications.
