## Why is This Prediction Reasonable?

Detailed mechanism of action data is not available in the data compiled for this report. Pharmacology data show that teplizumab is a humanized anti-CD3 antibody (a derivative of OKT3) that binds CD3e on T cells. It is understood to modulate T-cell activity and so delay the autoimmune destruction of pancreatic beta cells in type 1 diabetes.

Diabetic cataract is driven mainly by hyperglycaemia-induced activation of the polyol pathway and by oxidative stress in the lens. It is not an autoimmune, T-cell-mediated process. An indirect link is conceivable only if preserved beta-cell function improved long-term glycaemic control and so lowered cataract risk. That would be a downstream effect of disease modification, not a direct action on the lens.

The high TxGNN score is therefore best read as a computational signal, likely reflecting the drug's proximity to diabetes-related nodes in the knowledge graph. It is not biological evidence. The same score pattern appears across many other cataract subtypes (for example senile, mature and cortical cataract), which supports this interpretation. Several of the other top-ranked predictions, such as type 2 diabetes-associated cataract and type 2 antithrombin deficiency, also have no plausible mechanistic connection.
