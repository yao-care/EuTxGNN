## Why is This Prediction Reasonable?

Detailed mechanism-of-action data are not available in the compiled data. Based on published literature, lanadelumab is a monoclonal antibody that inhibits plasma kallikrein.

In C1 inhibitor deficiency (hereditary angioedema types I and II), loss of C1-inhibitor control leaves plasma kallikrein unchecked. This leads to excess bradykinin generation, which drives swelling attacks. Blocking kallikrein directly addresses this pathway, so the mechanistic fit is strong.

Note that the evidence indicates this prediction overlaps with the use already described in local licence records, so it works more as a validation of the model than as a true repurposing finding.

## Safety Considerations

Please refer to the SmPC for safety information.

One pharmacological interaction record exists: the drug's target is plasma kallikrein (KLKB1), consistent with its intended mechanism. Separately, lanadelumab may prolong aPTT through effects on the intrinsic pathway, which warrants caution in patients with bleeding disorders.
