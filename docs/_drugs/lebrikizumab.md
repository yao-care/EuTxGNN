Lebrikizumab (Ebglyss) is an interleukin-13 (IL-13) antibody, originally used to treat moderate-to-severe atopic dermatitis.

## Why is This Prediction Reasonable?

Currently, detailed mechanism of action data is not available in the compiled records. Published literature describes lebrikizumab as a high-affinity monoclonal antibody that binds IL-13. It prevents formation of the IL-4Rα/IL-13Rα1 signaling complex, which drives type 2 inflammation in atopic dermatitis. Its efficacy in atopic dermatitis is supported by multiple Phase 3 trials.

A possible link to diabetic retinopathy would be a role for IL-13 or type 2 inflammation in retinal inflammation. This is speculative. The data compiled for this report contain no clinical, preclinical, or literature evidence for it. The prediction is a graph-based score only. Atopic dermatitis (a skin disease) and diabetic retinopathy (a vascular and neurodegenerative eye disease) are also not closely related, so the similarity between the original and new indications has not been established.
